# План встроенного редактора Fresvik

## Цель

Дать авторизованному администратору возможность открыть опубликованную новость,
нажать `Rediger artikkel` / `Edit article`, изменить основные текстовые поля и
сохранить их непосредственно в Sanity. Для обычного посетителя внешний вид и
поведение страницы не меняются.

## Этап 1. Безопасный пилот для новостей

- Использовать существующую подписанную административную сессию.
- Показывать кнопку редактора только при действующей admin-cookie.
- На сервере определять Sanity-документ по текущему локализованному маршруту,
  типу `newsArticle`, slug и языку. Не принимать произвольный `_id` из браузера.
- Разрешить изменение только `title`, `date`, `excerpt` и `body`.
- Хранить `SANITY_AUTH_TOKEN` только на сервере; браузеру токен не передавать.
- После сохранения инвалидировать кеш изменённого маршрута и обновить страницу.

## Этап 2. Интерфейс редактирования

- Разместить под содержимым новости компактную административную панель.
- Загружать актуальные значения из Sanity только после открытия редактора.
- Валидировать поля и на клиенте, и на сервере.
- Показывать понятный результат сохранения и не менять публичный дизайн статьи.
- Локализовать административные подписи для NN и EN.

## Этап 3. Расширение после проверки пилота

- Добавить редактирование секций, подписей изображений, ссылок и документов.
- Добавить выбор и загрузку изображений через защищённый серверный маршрут.
- При необходимости перейти с прямой публикации на Sanity drafts и отдельную
  кнопку публикации.
- Подключить редактор к продуктам, услугам, референсам и обычным страницам через
  тот же защищённый механизм.

## Безопасность

- В production обязательны отдельные значения `ADMIN_USERNAME`,
  `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` и `SANITY_AUTH_TOKEN`.
- Все операции записи проверяют административную cookie и same-origin запрос.
- Сервер принимает только белый список полей и ограничивает длину текста.
- Публичный API не раскрывает токены, служебные поля и произвольные документы.
- Начальные `admin` / `admin` допустимы только для локальной разработки и должны
  быть заменены перед открытием сайта третьим лицам.

## Критерии готовности пилота

- Неавторизованный посетитель не видит редактор и получает `401` от API.
- Администратор может изменить NN- или EN-версию новости отдельно.
- После сохранения изменения появляются на текущей странице без ручного импорта.
- Изображения, документы, секции и миграционные поля остаются без изменений.
- `npm run lint` и `npm run build` проходят.
